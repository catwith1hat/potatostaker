Practical shopping list

Hardware Purchases That Matter

CPU / Host

Intel N100 mini-PC or similar low-power desktop

$180-$350

Prioritize stable thermals and a known-good board vendor.

RAM

16 GB minimum for one lightweight combo, 32 GB safer headroom

$35-$90

Memory pressure causes missed duties before CPU does.

NVMe SSD

1 TB minimum, TLC preferred, avoid unknown controllers

$55-$110

Drive quality is usually more important than peak throughput.

Power / Network

Small UPS and reliable wired ethernet

$70-$200

Power stability and uptime discipline improve rewards consistency.

Starter templates

Practical Client Configuration

Nimbus (CL)

# one-time sync
nimbus_beacon_node trustedNodeSync \
  --trusted-node-url=https://checkpoint-sync.<network>.ethpandaops.io/ \
  --backfill=false

# regular run
nimbus_beacon_node \
  --history=prune

Prysm Beacon (CL)

beacon-chain \
  --checkpoint-sync-url=https://beaconstate-<network>.chainsafe.io \
  --beacon-db-pruning

Lodestar (CL)

lodestar beacon \
  --checkpointSyncUrl=https://beaconstate-<network>.chainsafe.io \
  --serveHistoricalState
# Note: no explicit prune/history flag in this snippet.

Besu (EL)

besu \
  --sync-mode=CHECKPOINT \
  --data-storage-format=BONSAI \
  --history-expiry-prune

Nethermind (EL)

nethermind \
  --Pruning.Mode=Hybrid \
  --Pruning.FullPruningMemoryBudgetMb=16384 \
  --History.Pruning=Rolling \
  --Init.StateDbKeyScheme=HalfPath

Erigon (EL)

erigon \
  --prune.mode=full

Geth (EL)

geth \
  --syncmode=snap

Ethrex (EL)

ethrex \
  --syncmode=snap

Reth (EL)

reth node \
  --full
